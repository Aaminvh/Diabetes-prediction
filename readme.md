# Diabetes Prediction Dataset

## Project Overview

This project aims to predict diabetes status using machine learning techniques.

## Dataset

The dataset contains the following variables:

- gender
- age
- hypertension
- heart_disease
- smoking_history
- bmi
- HbA1c_level
- blood_glucose_level
- diabetes

## Project Structure

- Data/ : raw and processed datasets
- Notebook/ : Jupyter notebooks
- figures/ : plots and visualisations
- Outputs/ : model outputs
- src/ : Python scripts
- Tests/ : testing code
